Privacy Policy

Latest Release • Verifiable Zero-Telemetry

1. Privacy Statement & Data Sovereignty

Privacy AI Guard ("the Software", "the Platform", "We", "Our") is governed by a strict, non-negotiable architectural commitment to Local Data Sovereignty. The Platform is designed from the ground up so that users retain 100% control, ownership, and exclusive possession of their data.

Unlike conventional web extensions, browser tools, or commercial cloud AI platforms that record browsing behavior, extract tab contents, or transmit prompt histories to external servers, Privacy AI Guard operates entirely offline and locally within your browser and desktop environment.

2. Complete Absence of Data Collection (Zero Telemetry Guarantee)

Privacy AI Guard does not collect, harvest, aggregate, monetize, share, or transmit any user data. Specifically, We do not collect:

  • Browsing Activity & History: Visited URLs, page titles, tab metadata, session duration, and navigation paths remain strictly inside your local browser memory.
  • Web Page Content & Text Snippets: HTML markup, extracted text, and DOM contents analyzed by the local AI engine are processed in ephemeral local memory and never leave your machine.
  • User Credentials & Identifiers: Passwords, session cookies, auth tokens, personal names, email addresses, and IP addresses are completely excluded from prompt contexts and processing pipelines.
  • Telemetry & Usage Analytics: We do not track feature usage, button clicks, error logs, performance metrics, or system specifications. No analytics beacons or ping endpoints exist in our code.

3. Local Architecture & Security Mechanics

A. Local AI Processing Pipeline

All page summarization, query parsing, and vector retrieval-augmented generation (RAG) execute locally using small quantized models (GGUF format) running natively on your hardware:

  • DOM Sanitization Wall: Ephemeral DOM parsing strips hidden tracking elements (display:none, visibility:hidden, opacity:0, aria-hidden="true") prior to AI processing.
  • Indirect Prompt Injection Firewall: Untrusted webpage text is scanned for override patterns and isolated inside structural <untrusted_web_content> sandbox tags.

B. Local Storage & Encryption at Rest

Data persisted locally (such as local activity logs or vector index files) is stored in chrome.storage.local or local application directories. Vector indexes are encrypted at rest using keys derived from your operating system's native keychain.

4. Anti-Hacker Vulnerability Isolation & Anti-Exploit Security

Privacy AI Guard enforces robust defensive boundaries to protect your device against hacker exploits and malicious web scripts:

  • Zero Network Exposure: No listening sockets, open ports, or web servers are opened by the Software. External attackers on your local network or the internet cannot scan or connect to the system.
  • Native Host OS Sandboxing: The Rust native host companion enforces strict file path validation (sandbox/mod.rs) to block path traversal attempts or unauthorized OS command execution.
  • Closed Action Type Allowlist: Autonomous agent actions are restricted to a fixed schema (extract_text, click_element, fill_field, navigate, submit_form). Generic shell execution is impossible.

5. Code-Enforced Human Gate Authorization

To eliminate unauthorized state-changing actions by AI models or malicious web scripts, Privacy AI Guard enforces a code-level Human Confirmation Gate (executor.js). Sensitive actions (such as form submission or navigating outside approved domains) strictly refuse execution without an explicit, single-use user click confirmation token.

6. International Regulatory Compliance

Because Privacy AI Guard does not collect, process, transmit, or retain personal data on external systems, the Platform provides compliance with major global privacy directives:

  • EU General Data Protection Regulation (GDPR): Inherently compliant under Articles 5 and 6 (Data Minimization and Purpose Limitation). User data never leaves the data subject's device.
  • California Consumer Privacy Act (CCPA / CPRA): We do not sell, share, or cross-context track personal information. No consumer data request procedures are required because zero data is stored by Us.
  • Right to Erasure (Right to be Forgotten): Clearing your browser extension storage instantly and permanently deletes all locally retained activity logs.

7. Third-Party Links & External Web Content

While Privacy AI Guard blocks ad networks and tracking scripts, it operates on third-party web pages visited by the user. We are not responsible for the privacy practices, content, or security of third-party websites you visit.
