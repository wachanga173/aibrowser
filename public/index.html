Installation & Update Guide

1

Download Latest Build

Click Download Extension Package above to get the latest automatically compiled release .zip package from GitHub.

2

Load or Refresh in Browser

Open chrome://extensions, enable Developer mode, and click Load unpacked. If updating an existing version, simply extract the new zip over the folder and click the Refresh icon.

3

Automatic Update Reminders

The extension popup automatically checks for updates and notifies you inside the popup whenever a new version is ready.
