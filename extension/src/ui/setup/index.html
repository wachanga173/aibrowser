One-Time Setup

Enable Automatic Updates

To update the extension with one click, a small companion program needs to be installed on your computer. This only needs to be done once -- after setup, all future updates happen automatically from the extension popup.

  1. 1
    Download the setup script
    Click the button below to download the setup file. It will be saved to your Downloads folder.
  2. 2
    Move it to your extension folder
    Place the downloaded setup-native-host.bat file in the same folder where you extracted the extension.
  3. 3
    Run the setup script
    Double-click the file to run it. A terminal window will appear and complete the setup automatically.
  4. 4
    Verify the connection
    Come back here and click "Verify Setup" to confirm everything is working.
Download Setup Script
What does this install? A small local program (~2 MB) that allows the extension to download and apply updates to itself. It runs only when you click "Update Now" in the popup. No data is collected or sent anywhere -- all operations are local. The source code is fully open on GitHub.
